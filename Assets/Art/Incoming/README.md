# Real asset intake

Place licensed production assets here before scene wiring:

- `Characters/` — Android protagonist, enemy rigs and facial/helmet variants.
- `Animations/` — locomotion, locomotion additive, attacks, hit reactions and finishers.
- `Environments/` — Neo-Tokyo streets, interiors, props and decal atlases.
- `VFX/` — ability trails, impacts, shields and boss telegraphs.
- `Audio/` — combat impacts, UI cues, ambience and music stems.

Do not commit purchased asset packages or unlicensed marketplace files. Record the source and license in `Docs/Art/AssetRegister.md`.
